how this is measured
  • Two throwaway clients queue and play one real match against each other.
  • Every frame carries the server's own send time. Late by is the gap between that and when your browser got it, corrected for clock skew.
  • The count above is not a recording — it runs kxp.js's real countdownSchedule, the same code the game uses, so what you see is what a player would see.
  • The countdown is announced exactly as long before PUN as it lasts, so there is no built-in slack. Each second of delay costs one beat.
